# MVP 项目任务看板

## 1. 看板目标

本文档用于把需求文档和开发计划转换为可执行的 MVP 任务看板。  
适合直接复制到 GitHub Projects、Linear、Jira、飞书项目或其他任务管理工具中。

MVP 的核心目标：

- 用户可以通过邮箱验证码登录。
- 用户可以创建情侣关系并邀请另一位用户加入。
- 双方可以每日提交心情打卡。
- 首页可以展示关系天数、双方状态和连续打卡。
- 用户可以维护一个共同目标并添加金额进度。
- 用户可以通过日历查看历史记录。
- 用户可以发送和查看今日一言/消息。
- 用户可以在我的页面查看邀请码和基础设置。

## 2. 优先级定义

| 优先级 | 含义 | 说明 |
| --- | --- | --- |
| P0 | MVP 必须完成 | 缺失后产品主流程不可用 |
| P1 | MVP 推荐完成 | 缺失后体验下降，但可临时绕过 |
| P2 | 可延期 | 不影响首期验证 |

## 3. 状态定义

| 状态 | 含义 |
| --- | --- |
| Todo | 未开始 |
| Ready | 需求明确，可进入开发 |
| In Progress | 开发中 |
| Blocked | 被依赖、决策或外部资源阻塞 |
| Review | 待代码审查或设计审查 |
| QA | 待测试验收 |
| Done | 已完成并通过验收 |

## 18. MVP 最终验收清单

产品功能：

- 用户可以登录。
- 用户可以创建关系并复制邀请码。
- 第二个用户可以通过邀请码加入。
- 首页显示双方头像、昵称、关系天数和连续打卡。
- 用户可以选择心情并提交日记。
- 今日双方状态展示正确。
- 用户可以查看和更新共同目标金额。
- 用户可以通过日历查看历史记录。
- 用户可以发送和查看消息。
- 用户可以在我的页面查看关系和设置。

- 前端生产构建通过。
- 后端服务可启动。
- 数据库迁移可执行。
- Swagger/OpenAPI 可访问。
- 核心接口有权限校验。
- 验证码和邀请码有基础限流/防护。
- 移动端主要宽度无明显布局问题。
- 演示环境可完成完整主流程。

交付物：

- 前端代码仓库。
- 后端代码仓库或单体仓库后端目录。
- 数据库迁移文件。
- `.env.example`。
- OpenAPI 文档。
- 种子数据。
- 部署说明。
- MVP 验收记录。
